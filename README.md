# Izzy’s Imaginary Friends — website draft

Continues the existing ChatGPT starter website and its original rainbow branding and artwork.

## Preview locally

Download this repository and open `index.html` in a browser. No installation or build is needed. Keep `style.css` and the `assets` folder beside it.

## Edit the draft

- `index.html`: homepage copy, navigation and gallery.
- `style.css`: colours, spacing and responsive layouts.
- `assets/logo.webp`: original rainbow logo with Cookie/Ginger, Heart and Banana.
- `assets/izzy-ant.webp`: original Izzy the Ant artwork.
- `assets/bookmarks.webp`: original bookmark collection featuring the friends and additional artwork.

The images are imported unchanged from `izzys-imaginary-friends-starter.zip`. Gallery links open the full artwork. Etsy, Facebook and Instagram links can be added once their addresses are confirmed.

## Draft status

Repository files only. GitHub Pages is not enabled, no domain is configured and no deployment workflow is included. Publishing is a separate future step requiring Dave’s instruction.
